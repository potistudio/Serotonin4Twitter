# Serotonin for Twitter

X（Twitter）のタイムラインを、スクロールやなくて **1枚ずつのカード** で表示する Chrome 拡張やで。

## インストール

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダ（`tl-card-slider`）を選ぶ
4. x.com を開けばカード表示になっとる

Edge / Brave とか Chromium 系ならだいたい同じ手順でいけるで。

## 操作

| 操作 | 動き |
| --- | --- |
| `↓` `→` `J` `Space` / ホイール下 / 上スワイプ | 次のポスト |
| `↑` `←` `K` `Shift+Space` / ホイール上 / 下スワイプ | 前のポスト |
| `L` `R` `T` `Enter` | いいね / 返信 / リポスト / 開く（Xの標準ショートカットがそのまま今のカードに効く） |
| `Alt+S` | カード表示のON/OFF |
| 画面下の操作バー | 前 / 次 / ON/OFF |

- 画面に収まらん縦長カードは、まずカードの中をスクロールして、端まで行ったら次のカードに進むで
- ホイールは「1スワイプ＝1枚」。トラックパッドの慣性で何枚も飛ばんようにしとる
- ツールバーのアイコンから、アニメーション（横スライド / 縦スライド / フェード / なし）とフォーカスモード（右サイドバーを隠す）が選べる

## 仕組み

- Xの本物のDOMをそのまま使っとる（クローンせえへん）から、いいね・リプ・画像・動画・メニューは全部普通に動く
- 今のカード以外の `cellInnerDiv` を透明にして、ページのスクロール位置を拡張側で1枚ずつ合わせとるだけ
- Xのタイムラインは仮想リスト（画面外のポストはDOMから消える）やから、次/前のカードがまだ無いときは一旦スクロールして読み込ませてから切り替える
- 個別ポスト画面（`/status/…`）・DM・通知・設定では無効。普通のスクロールのままや

## 注意

- Xの `data-testid`（`primaryColumn` / `cellInnerDiv` / `tweet`）に依存しとるから、X側のDOM変更で動かんくなる可能性はある
- 実際の x.com ではまだ検証してへん（ログインが要るから）。X風の仮想リストを再現したテストページでは確認済み

## ファイル

```
manifest.json   拡張の定義（Manifest V3）
content.js      本体（カード切り替え・入力処理・操作バー）
content.css     カード表示・アニメーション
popup.html/js   設定ポップアップ
icons/          アイコン
```
